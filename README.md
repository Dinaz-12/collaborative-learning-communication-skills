# Collaborative Learning Improves Students' Communication Skills

## Overview

This research project was conducted for the Theory and Practices in Statistical Modelling (TPSM) module at Sri Lanka Institute of Information Technology (SLIIT) as part of the Data Science Specialization.

The objective of this study was to investigate whether collaborative learning has a statistically significant impact on students' communication skills using the PISA 2018 dataset.

## Dataset

* Source: PISA 2018 Student Questionnaire Dataset
* Sample Size: 130,000+ student records
* Data preprocessing and analysis performed using R

## Methodology

1. Data Collection and Cleaning
2. Data Preprocessing
3. Descriptive Statistical Analysis
4. Pearson Correlation Analysis
5. Linear Regression Modelling
6. Result Interpretation

## Key Findings

* A statistically significant positive relationship was found between collaborative learning and communication skills.
* Pearson Correlation Coefficient: r = 0.216
* The relationship was positive but weak.
* Linear Regression analysis indicated that collaborative learning positively contributes to communication skills.
* Statistical significance does not necessarily imply a strong practical impact.
